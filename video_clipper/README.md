# Video Clipper — автоматический нарезчик коротких видео

Десктопное приложение для автоматической нарезки длинных видео (шоу, стримов, сериалов)
на короткие вертикальные клипы (YouTube Shorts / TikTok / Instagram Reels).

## Возможности

1. **Графический интерфейс** на CustomTkinter с тёмной темой.
2. **Извлечение аудиодорожки** из видео через MoviePy.
3. **Распознавание речи** локальной моделью OpenAI Whisper с таймкодами.
4. **Поиск хайповых моментов** по ключевым словам, смеху, аплодисментам, крикам.
5. **Автоматическая нарезка** в вертикальный формат 9:16 с эффектом размытия фона
   (для обхода фильтров уникальности YouTube).
6. **Наложение рекламного баннера** (PNG с прозрачностью) в верхнюю или нижнюю часть клипа.

## Установка

```bash
# 1. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate            # Linux/macOS
venv\Scripts\activate               # Windows

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Установить ffmpeg в систему (требуется для moviepy и whisper)
#    Windows:  https://www.gyan.dev/ffmpeg/builds/
#    macOS:    brew install ffmpeg
#    Linux:    sudo apt install ffmpeg
```

## Запуск

```bash
python main.py
```

## Как пользоваться

1. Запустите приложение: `python main.py`.
2. Нажмите **«Обзор…»** и выберите видеофайл (mp4 / mkv / mov / avi / webm).
3. (Опционально) укажите ключевые слова через запятую, например:
   `смех, шок, неожиданно, вау, провал, ого`.
4. (Опционально) выберите PNG-баннер и его положение.
5. Длительность клипа по умолчанию **60–90 сек** (~1.5 минуты).
6. Нажмите **«▶ Запустить»** — приложение само:
   - извлечёт аудио,
   - распознает речь (Whisper),
   - найдёт самые «хайповые» моменты,
   - нарежет вертикальные клипы 9:16 с размытым фоном,
   - (опционально) наложит баннер.
7. Готовые файлы лежат в выбранной папке вывода — нажмите
   **«📂 Открыть папку»**, чтобы забрать их.
